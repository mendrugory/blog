After this year's [Facebook F8](https://en.wikipedia.org/wiki/Facebook_F8), the new buzzword is *ChatBot*, so I decided to build one using the [Telegram Bot API](https://core.telegram.org/bots/api).

My ChatBot is called [Monkey Note Bot](https://telegram.me/MonkeyNoteBot). It is a Telegram bot that takes care of your lists of notes.

If you type a command like "Addnotes shopping bread. milk. eggs" (dots are easier than commas to type on a phone), MonkeyNoteBot will add the given notes to the "shopping" list. If the list does not exist, it will be created.

The code can be found on [github](https://github.com/mendrugory/monkey-note-bot).

Give the [Monkey](https://telegram.me/MonkeyNoteBot) a chance!
