[Opensouthcode](https://www.opensouthcode.org) is an event based in Málaga (Spain) whose goal is to promote open source technologies.

This year I was there giving a talk about *Infrastructure as code* using *Terraform* and showing some examples that were deployed to *AWS*: from a simple server to a *Kubernetes* cluster.

If you want to learn more, check all the sources:

* [GitHub repo with the examples](https://github.com/mendrugory/opensouthcode2019)
* [Slides](https://mendrugory.github.io/opensouthcode2019/#/) (Spanish)
